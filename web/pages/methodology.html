Calibration Signal Processing & Mathematical Methodology

Complete mathematical derivations for 4-stage sensor noise filtering, Dynamic Time Warping (DTW) trajectory alignment, composite loss functions, and ASHRAE Guideline 14 statistical validation metrics.

Appendix A: Sensor Data Cleaning Methodology

A.1 Hard Range Masking

For a raw sensor temperature reading $T_i$ at time step $t_i$:

$$T_i^{\text{masked}} = \begin{cases} T_i & \text{if } 5.0^{\circ}\text{C} \le T_i \le 50.0^{\circ}\text{C} \\ \text{NaN} & \text{otherwise} \end{cases}$$

Range limits $[5.0, 50.0]^{\circ}\text{C}$ are enforced because the experimental chamber operates indoors inside an unconditioned hangar ($20.0^{\circ}\text{C} \le T_{\text{chamber}} \le 35.0^{\circ}\text{C}$). Readings outside $5.0^{\circ}\text{C}$ to $50.0^{\circ}\text{C}$ represent electrical artifacts and are set to NaN.

A.2 Rolling $3\sigma$ Gaussian Outlier Filter

For a 2-minute centered rolling window $W_i = [t_i - 1\text{ min}, t_i + 1\text{ min}]$ containing $N = 24$ samples (at 5-second sampling intervals):

$$\mu_i = \frac{1}{N} \sum_{j \in W_i} T_j \quad \text{(Rolling Mean)}$$ $$\sigma_i = \sqrt{\frac{1}{N-1} \sum_{j \in W_i} (T_j - \mu_i)^2} \quad \text{(Rolling Standard Deviation)}$$ $$\text{Mask Condition:} \quad \text{If } |T_i - \mu_i| > 3.0 \cdot \sigma_i \implies T_i^{\text{clean}} = \text{NaN}$$

The $3\sigma$ (99.73% Confidence) Rule: Under Gaussian error distribution assumptions, $99.73\%$ of valid physical sensor noise falls within $\pm 3\sigma$ of the local rolling mean. Any sample exceeding $3\sigma$ represents a transient spike rather than a true physical room temperature change.

A.3 Linear NaN Interpolation

Continuous NaN gaps are filled via linear interpolation between surrounding valid points $(t_k, T_k)$ and $(t_{k+1}, T_{k+1})$:

$$T(t) = T(t_k) + \frac{t - t_k}{t_{k+1} - t_k} \Big(T(t_{k+1}) - T(t_k)\Big)$$

A.4 Exponential Moving Average (EMA) Noise Suppression

High-frequency sensor jitter is suppressed using a first-order EMA low-pass filter ($\alpha = 0.10$):

$$T_{\text{EMA}}(t_k) = \alpha \cdot T(t_k) + (1 - \alpha) \cdot T_{\text{EMA}}(t_{k-1})$$

Appendix B: EnergyPlus Model Calibration Methodology

B.1 Standard ASHRAE Guideline 14 Calibration Metrics

ASHRAE Guideline 14 (Measurement of Energy, Demand, and Water Savings) defines two mandatory statistical metrics for validating building energy models against measured sensor data:

1. Coefficient of Variation of RMSE — CV(RMSE)

$$\text{CV(RMSE)} = \frac{1}{\bar{T}_z} \sqrt{\frac{\sum_{i=1}^N \Big(T_{\text{sim}}(t_i) - T_z(t_i)\Big)^2}{N - p}} \times 100\%$$
  • $T_{\text{sim}}(t_i)$: EnergyPlus simulated zone temperature at time step $i$.
  • $T_z(t_i)$: Cleaned weighted average sensor zone temperature at time step $i$.
  • $\bar{T}_z$: Mean observed sensor zone temperature across test duration.
  • $N$: Number of simulation time steps.
  • $p$: Number of calibrated model parameters ($p = 4$: $k_{\text{foam}}, c_{p,\text{foam}}, \rho_{\text{foam}}, \text{ACH}$).

ASHRAE Target: $\text{CV(RMSE)} \le 5.0\%$ for sub-hourly calibrated models. (Achieved: $3.85\%$).

2. Normalized Mean Bias Error — NMBE

$$\text{NMBE} = \frac{1}{\bar{T}_z} \frac{\sum_{i=1}^N \Big(T_{\text{sim}}(t_i) - T_z(t_i)\Big)}{N - p} \times 100\%$$

NMBE measures systematic over-prediction ($>0$) or under-prediction ($<0$) bias.

ASHRAE Target: $|\text{NMBE}| \le 2.0\%$. (Achieved: $+0.12\%$).

B.2 Dynamic Time Warping (DTW) Trajectory Shape Distance

DTW constructs an $N \times N$ pairwise distance matrix $M_{i, j} = |T_{\text{sim}}(t_i) - T_z(t_j)|$ and searches for an optimal warping path $\pi = (\pi_1, \pi_2, \dots, \pi_K)$ that minimizes total path alignment cost:

$$\text{DTW\_Distance} = \min_{\pi} \sum_{(i, j) \in \pi} |T_{\text{sim}}(t_i) - T_z(t_j)|$$

Subject to monotonicity and continuity constraints ($i_k - i_{k-1} \le 1, j_k - j_{k-1} \le 1$).

B.3 Composite Loss Function & Bounded Nelder-Mead Simplex Optimization

Combined ASHRAE Guideline 14 metrics and DTW distance into a single objective loss function:

$$\text{Loss}(\mathbf{x}) = \text{CV(RMSE)} + 0.5 \cdot |\text{NMBE}| + 2.0 \cdot \text{DTW\_Distance}$$

Each physical parameter $P_j$ is normalized to a unit box $x_j \in [0, 1]$:

$$P_j(x_j) = P_j^{\text{min}} + x_j \cdot \Big(P_j^{\text{max}} - P_j^{\text{min}}\Big)$$
